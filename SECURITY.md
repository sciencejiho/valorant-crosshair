# Security Policy

## Supported Versions

Security fixes are applied to the latest version on `main`.

## Reporting a Vulnerability

Please report vulnerabilities privately through GitHub's **Security** tab by
opening a private security advisory. Do not include exploit details, tokens,
or personal information in a public issue.

Include the affected command or API, reproduction steps, impact, and any
suggested mitigation. You should receive an acknowledgement within seven days.

Crosshair Lab is intentionally offline and must not access VALORANT process
memory, game files, anti-cheat systems, or automated input APIs.
